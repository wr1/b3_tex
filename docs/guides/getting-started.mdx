## Requirements

| Need | Notes |
|------|--------|
| **Python** | 3.12 recommended |
| **micromamba / conda** | DOLFINx from conda-forge (optional if you only use MFEM) |
| **PyMFEM** | Recommended backend (`mfem-periodic` + hex AMR) |
| **treeparse** | CLI |
| **Typst** | Optional; datasheet PDF only |

## Install

```bash
pip install 'b3-tex[mfem]'
```

The PyPI package is `mfem` (the `[mfem]` extra), not `pymfem`. It also installs
`numba`. Skip DOLFINx if you only need MFEM.

Optional DOLFINx backends are conda-forge only (not a pip extra):

```bash
micromamba create -n b3-tex -c conda-forge \
    python=3.12 fenics-dolfinx dolfinx_mpc mpich
micromamba activate b3-tex
pip install 'b3-tex[mfem]'
```

## First commands

```bash
# Load + sanity (micromodel, AMR, yarn Vf estimate)
b3-tex validate examples/ud_tow.yaml

# Analytical bounds
b3-tex reference examples/ud_tow.yaml

# Homogenize → C_eff.npz + C_eff.meta.json
b3-tex solve examples/ud_tow.yaml -o results/ud_tow

# One-page datasheet (reuse prior C_eff)
b3-tex datasheet examples/ud_tow.yaml \
  -o results/datasheet_ud_tow.pdf \
  --c-eff results/ud_tow/C_eff.npz

# Textile-as-code card (preferred for weaves)
b3-tex validate examples/weave_twill_2x2.py
b3-tex solve    examples/weave_twill_2x2.py -o results/weave_twill_2x2
```

Cards may be **YAML** or **Python** (`build() -> RVEProblem`). Authoring API:
[Textile-as-code](/docs/reference/textile-as-code).

## Recommended defaults

| Setting | Prefer |
|---------|--------|
| Backend | `mfem-periodic` (CLI default) |
| Cell type | `hexahedron` for weaves + AMR |
| Sampling | `local_cloud`, resolution ≥ 6 |
| AMR | `max_iterations: 2`, `threshold: 0.2` |

See [Convergence & cost](/docs/guides/convergence) for smoke vs publish meshes.
